# JAPANESE ZEN FUTURISM
## Visual Direction & Design System — Developer Portfolio

### 1. Project Vision

Create a modern, immersive, minimalist, and sophisticated full-stack developer portfolio inspired by contemporary Japanese architecture, the Japanese concept of *Ma* (間), and futuristic digital interfaces.

The portfolio should communicate precision, tranquility, technical expertise, and exceptional attention to detail.

**Core principle:** Technology should feel natural, not overwhelming.

The overall experience should feel like entering a quiet, carefully designed architectural space where every element has a purpose.

### 2. Technology Stack

- **Framework:** Next.js with App Router
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Motion
- **Package Manager:** pnpm
- **Visual Direction:** Impeccable for design refinement, visual consistency, and interface quality

Prioritize performance, accessibility, responsiveness, and maintainable component architecture.

### 3. Hero Section — Architectural Atmosphere

**Primary background:** Use the Japanese architectural image provided by the user.

The image features a dark Japanese-inspired interior, symmetrical architectural elements, natural materials, and a striking circular light source.

This image should establish the visual identity of the entire portfolio.

**Background treatment:**

- Display the image as a full-screen architectural background.
- Use `background-size: cover` while preserving the central composition.
- Keep the circular light source visible whenever possible.
- Apply a subtle cinematic gradient overlay to ensure text readability.
- Preserve the image's original warm tones and natural textures.
- Avoid excessive blur, artificial neon effects, or aggressive color grading.
- The architecture must remain atmospheric rather than becoming the primary focal point.

**Hero composition:**

- Minimal, transparent navigation header.
- Personal branding positioned in the upper-left corner.
- Navigation links aligned to the upper-right corner.
- Large, expressive typography introducing the developer.
- Subtle Japanese typography with meaningful translations.
- A refined call-to-action leading to selected projects.
- Minimal scroll indicator near the bottom of the viewport.

Position the main content toward the left side of the screen, allowing the architectural composition to remain visible.

The illuminated circular element should not be unnecessarily obstructed by typography.

### 4. Color System

The visual identity should use a restrained, dark color palette inspired by Japanese architecture, natural stone, moonlight, and futuristic interfaces.

| Token | Hex | Purpose |
|---|---|---|
| Void | `#090B0E` | Primary background |
| Charcoal | `#15191D` | Secondary surfaces |
| Stone | `#25292D` | Borders and dividers |
| Moonlight | `#F1F0EB` | Primary text and headings |
| Ash | `#A5A7A6` | Secondary text |
| Mist Blue | `#8CCFE6` | Interactive accents |

**Color guidelines:**

- Dark neutral colors should dominate the interface.
- Use Moonlight for important headings and readable content.
- Use Ash for secondary information and supporting descriptions.
- Mist Blue should appear sparingly in interactive elements, navigation indicators, and subtle highlights.
- Preserve the architectural photograph's warm, natural color palette.
- Avoid oversaturated gradients and excessive neon lighting.

The contrast between warm architectural materials and cool technological accents should define the portfolio's character.

### 5. Typography

Typography should be expressive, carefully structured, and highly readable.

**Primary typeface — Geist**

Use for headings, navigation, body text, and primary interface elements.

**Technical typeface — Geist Mono**

Use for project numbering, metadata, technology labels, and technical information.

**Japanese typeface — Noto Sans JP**

Use for meaningful Japanese text and subtle cultural references.

**Typography principles:**

- Large, confident headings.
- Strong visual hierarchy.
- Generous spacing between sections.
- Minimal use of decorative typography.
- Carefully balanced line lengths.
- Consistent tracking and font weights.
- Meaningful Japanese labels accompanied by accurate translations.

Avoid using Japanese characters purely as decoration.

### 6. Portfolio Structure

#### 01 — Hero / Introduction

A cinematic introduction featuring the architectural background, developer identity, professional title, and primary call-to-action.

The section should immediately establish the portfolio's visual identity.

#### 02 — Selected Work / Projects

Present featured projects through an editorial layout.

Each project should include:

- Large, high-quality project visuals.
- Project name and concise description.
- Technologies used.
- Links to live demonstrations and source code, when available.
- Minimal project numbering such as `01 / 02 / 03`.

Prioritize generous spacing and visual storytelling over generic card-based layouts.

#### 03 — About / Philosophy

Introduce the developer's background, professional journey, and approach to software development.

Use a clean, editorial composition with thoughtful typography.

The section should communicate personality without becoming visually overwhelming.

#### 04 — Expertise / Technologies

Present technical skills through carefully organized categories.

Avoid artificial progress bars, percentage indicators, or excessive technology logos.

Focus on clarity, hierarchy, and meaningful information.

#### 05 — Contact / Connection

Create a minimal yet memorable final section.

Include a strong call-to-action, professional links, and relevant contact information.

The ending should feel intentional, calm, and consistent with the overall experience.

### 7. Motion Design & Interactions

Animations should reinforce the calm, sophisticated atmosphere of the interface.

**Recommended interactions:**

- Subtle fade-in animations with gentle vertical movement.
- Progressive typography reveals.
- Extremely light parallax effects on the Hero background.
- Smooth hover transitions on project previews.
- Refined navigation interactions.
- Subtle lighting effects on interactive elements.
- Carefully timed section transitions.

**Motion principles:**

- Every animation must serve a purpose.
- Favor smooth, natural easing.
- Avoid excessive movement.
- Keep interaction feedback responsive.
- Respect `prefers-reduced-motion`.
- Maintain consistent performance across devices.

Avoid glitch effects, constant particles, aggressive transitions, and unnecessary 3D elements.

The interface should feel alive without demanding attention.

### 8. Responsive Design

**Desktop**

Prioritize cinematic composition, generous negative space, large typography, and immersive architectural imagery.

**Tablet**

Adapt typography, spacing, navigation, and project layouts while preserving the visual hierarchy.

**Mobile**

Prioritize readability, touch-friendly interactions, and carefully controlled image cropping.

Keep the architectural circle visible whenever practical, without sacrificing content readability.

Ensure animations remain smooth on lower-powered devices.

### 9. Japanese Design Philosophy

The portfolio should incorporate Japanese design principles naturally rather than relying on stereotypical visual elements.

**Ma (間) — Intentional Negative Space**

Use empty space to create rhythm, clarity, and balance.

**Kanso (簡素) — Simplicity**

Remove unnecessary visual elements and prioritize essential information.

**Shibui (渋い) — Subtle Elegance**

Favor restrained sophistication over obvious decoration.

**Seijaku (静寂) — Tranquility**

Create a calm atmosphere through controlled movement, balanced composition, and visual restraint.

These principles should guide the interface's structure, spacing, and interactions.

### 10. Visual Identity Rules

- Avoid excessive glassmorphism.
- Do not use aggressive neon gradients.
- Avoid generic card-heavy layouts.
- Do not introduce random Japanese symbols or decorative elements.
- Preserve the architectural image as an atmospheric background.
- Prioritize authentic content and well-presented projects.
- Maintain consistent spacing, typography, colors, and animations.
- Use visual effects only when they enhance the experience.
- Favor thoughtful composition over visual complexity.
- Keep the interface professional, accessible, and technically refined.

### 11. Expected Experience

The final portfolio should feel like a digital interpretation of contemporary Japanese architecture.

A quiet, immersive environment where precision, simplicity, and technology coexist.

The visitor should experience a sense of calm sophistication while discovering the developer's work.

The design should feel intentional, memorable, and distinctly personal without sacrificing usability.
